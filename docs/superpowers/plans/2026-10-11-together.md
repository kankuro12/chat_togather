# Together Implementation Plan

> For agentic workers: use superpowers:executing-plans. Execute directly under user's automatic workspace approval.

**Goal:** Deliver pair-only live chat, media choices/ratings, trips and schedules on Ionic Angular web and Capacitor mobile.

**Architecture:** Express/Socket.IO service owns authenticated couple access and SQLite persistence. Ionic standalone Angular frontend consumes authenticated REST and room updates; Capacitor packages the same frontend.

**Tech Stack:** Node 24, TypeScript, SQLite, Express, Socket.IO, Angular 20, Ionic 8, Capacitor 7.

**Spec:** ../specs/2026-10-11-couple-app-design.md

## Global constraints
Exactly two accounts per couple; identity selects room; all media private. Choice cards have 2–6 options, ratings 1–5. UTC agenda instants plus IANA timezone. No E2EE claim. Preserve old documents until replacement docs are ready.

## Review focus
Concurrent invite use cannot admit a third member. Foreign IDs must fail across every resource. Revoked sessions must lose socket access. DST/date conversion cannot silently shift schedules. Reconnection and resends must not duplicate messages.
